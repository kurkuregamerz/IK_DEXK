# IK DEXK ⌨️
IK DEXK is a macropad that has 9 MX Keyboard switches and 1 OLED 0.91 inch Display.

## Features ✨
*  It includes an 0.91 inch OLED display.
*  Custom Macros for efficiency.
*  Has high performance Cherry MX Switches with white keycaps.
*  Custom PCB and Case.

## THE PROCESS 🛠️
I at first designed the Macropad to be 3x3 but during designing I made some mistakes which later in firmware development caused a huge problem.
So when I ran into that problem I thought that now I know how things work so why not make it larger. That is why I made the macropad 4x4.
